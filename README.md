# Finance KZ

Информационный сайт о **МФО Казахстана** и **банковских картах**.
MVP информационного портала с расчётами, SEO-разметкой и местами под партнёрские ссылки.

Модель монетизации: affiliate/CPA, рекламные размещения, SEO-трафик.

---

## Стек

| Слой | Технология | Почему |
|---|---|---|
| Фреймворк | **Astro 7** (`output: 'static'`) | Статический HTML — лучший вордпресс для SEO, быстрый, минимум JS |
| Стили | **Чистый CSS** + CSS-переменные | Нет сборщика CSS, нет лишних зависимостей, полный адаптив |
| Контент | **Content Collections** (`glob` loader) + Markdown | Статьи пишутся в `.md`, типы проверяются схемой `zod` |
| SEO | `@astrojs/sitemap` + ручной SEO-слой | `sitemap.xml`, `robots.txt`, canonical, OG, Twitter, JSON-LD |
| Типы | TypeScript (`strict`) | `npm run check` ловит ошибки до сборки |
| Сборка | Vite (внутри Astro) | Стандарт, без доп. настройки |

Бэкенда нет: данные лежат в TypeScript-файлах, всё рендерится на этапе сборки.

## Запуск

```bash
npm install     # установка зависимостей (один раз)
npm run dev     # локальный сервер разработки
npm run build   # production-сборка в dist/
npm run preview # предпросмотр собранного сайта
npm run check   # проверка типов
```

**Локальный URL:** http://localhost:4321/

> Windows / PowerShell: если `npm` блокируется политикой выполнения скриптов,
> используйте `npm.cmd` вместо `npm`.

### Запуск в другой порт

```bash
npm run dev -- --port 3000 --host 127.0.0.1
```

## Как добавить новую организацию

**МФО** — добавьте объект в массив `MFO_OFFERS` в `src/data/mfo.ts`.
Страница `src/pages/mfo/[slug].astro` построится автоматически через `getStaticPaths`.

```ts
{
  slug: 'kivku',
  name: 'Kivku',
  logoText: 'KV',
  affiliateUrl: 'https://pxl.leads.su/click/...',
  cta: 'Получить займ',
}
```

Кнопка «Получить займ» на карточке и на странице организации ведёт ровно на `affiliateUrl`.

### Условия займа — только подтверждённые

Поля условий **опциональны и намеренно не заполнены**: `minAmount`, `maxAmount`,
`minTermDays`, `maxTermDays`, `aprAnnual`, `gesv`, `minAge`, `maxAge`, `online`,
`fastMinutes`, `installment`, `methods`, `requirements`, `features`, `pros`, `cons`,
`rating`, `reviewsCount`.

Сайт показывает только заполненные поля. Пока условия не подтверждены по официальному
источнику, на сайте нет ни таблицы сравнения, ни блоков «сумма / ставка / срок» —
вместо них показывается пояснение. Это сделано намеренно: непроверенная ставка в
финансовом справочнике вреднее, чем её отсутствие.

Как только условия будут проверены, заполните нужные поля в `MFO_OFFERS` — таблица,
спецификация и фильтры включатся автоматически.

### Внутренняя статистика партнёра

Метрики партнёрской сети (CR, AR, EPC, EPL, FTD) — внутренние данные партнёра.
На сайт они не выводятся и не должны попадать в `MFO_OFFERS`.

**Карта** — объект в `CARD_OFFERS` в `src/data/cards.ts`.

**Статья** — `.md`-файл в `src/content/articles/`. Frontmatter:

```markdown
---
title: 'Заголовок статьи'
description: 'Краткое описание для SEO и превью'
date: 2026-09-20
category: 'mfo'          # mfo | cards | general
tags: ['тег', 'тег']
readingMinutes: 5
---
```

Новый URL появится в `sitemap.xml` при следующей сборке.

## Партнёрские ссылки

Офферы МФО — реальные предложения партнёрской сети **ZaimStore**. Ссылки лежат в поле
`affiliateUrl` каждой организации в `src/data/mfo.ts`:

```ts
{
  slug: 'kivku',
  name: 'Kivku',
  affiliateUrl: 'https://pxl.leads.su/click/98829f8e93ae8f5d61d70110e3da4797',
  cta: 'Получить займ',
}
```

Кнопка «Получить займ» в карточке каталога и на странице организации ведёт ровно на
`affiliateUrl`. Атрибуты проставляются компонентом и на карточке, и в
`AffiliateBlock.astro`: `rel="sponsored nofollow noopener"`, `target="_blank"`, метка «Реклама».

Текст партнёрского раскрытия — константа `PARTNER_DISCLOSURE` в `src/config/site.ts`:
> Партнёрские предложения. При переходе по ссылке мы можем получить вознаграждение.
> Это не влияет на условия предложения.

Показан на `/mfo`, на главной (секция МФО) и на каждой странице организации.

Для банковских карт ссылки остаются заглушками (`example.com`) в `src/data/cards.ts`
и в `AFFILIATE` в `src/config/site.ts` — их нужно заменить перед публикацией.

## Что уже работает

- **Главная** — hero, калькулятор переплаты (сумма / срок / ставка), подборки МФО, карт и статей, блок «как это работает».
- **Каталог МФО** — 10 реальных офферов ZaimStore, кнопка «Получить займ» в каждой карточке, клиентские фильтры, партнёрская пометка, FAQ.
- **Каталог карт** — сравнительная таблица, 6 карточек, фильтры (бесплатное обслуживание / виртуальные / дебетовые / кредитные), FAQ.
- **Карточки МФО и карт** — плюсы/минусы, требования, партнёрский блок, похожие предложения, FAQ, JSON-LD.
- **7 статей** — Markdown, оглавление по темам, связанные материалы, JSON-LD `Article`.
- **Адаптив** — мобильное меню-бургер, адаптивные сетки, брейкпоинты 900 / 960 / 1000 px, `prefers-reduced-motion`, стили для печати.
- **SEO** — уникальные `title`/`description` на всех страницах, canonical, OG/Twitter, JSON-LD (`WebSite`, `Organization`, `ItemList`, `Article`, `FAQPage`), `sitemap.xml`, `robots.txt`, один `h1` на страницу, alt-тексты, `lang="ru"`, geo-мета для Казахстана.

## Перед публикацией в прод

1. Заменить `site` в `astro.config.mjs` и `url` в `src/config/site.ts` на реальный домен.
2. Заполнить контакт (`CONTACT.email`) и реквизиты в футере.
3. **Условия МФО.** В каталоге МФО не публикуются суммы, ставки, сроки, ГЭСВ и возраст — они не подтверждены. Заполните поля в `MFO_OFFERS` после проверки по официальным источникам: таблица сравнения, спецификации и фильтры включатся автоматически.
4. **Условия банковских карт** сейчас демонстрационные (названия банков реальные) — сверить с действующими тарифами.
5. Подключить хостинг (Netlify / Vercel / Cloudflare Pages): папка сборки — `dist`, команда — `npm run build`.

## Чего пока нет (сознательно, MVP)

Регистрация, личный кабинет, платежи, заявки на кредит, скоринг, база данных,
API банков и МФО, авторизация, админка.

## Техническая оговорка

npm в этой среде блокирует postinstall-скрипты (`esbuild`). Бинарник esbuild
подставляется через optional dependency `@esbuild/win32-x64`, поэтому сборка
работает без проблем. Если встретите ошибку про esbuild — выполните
`npm install-scripts approve esbuild`.

## Дисклеймер

Finance KZ — информационный сайт, а не финансовая организация. Здесь нет заявок
на займы, одобрения кредитов и сбора персональных данных. Условия организаций
показаны справочно и могут измениться — сверяйте их с официальным договором
и данными Национального банка Республики Казахстан.
